## 1. 成本价域名

第一个，是域名本身。

Cloudflare 卖域名，页面上就写着：以成本价查找并注册新域名，无加价。一个 .com 域名，一年十美元出头。

怎么买：左侧菜单「域名」→「注册域名」，搜索你想要的名字。

![image](https://pub-8dc0158e77a140d4b502b52ab75765b5.r2.dev/docs/0baf98338355dafd.jpg)

要注意的坑：有些后缀首年打折，续费会贵不少。比如 .dev，首年1 美元，续费要 12.2 美元一年。买之前，看一眼价格下面那行小字写的续费价。

![image](https://pub-8dc0158e77a140d4b502b52ab75765b5.r2.dev/docs/cf296dc2eb68de66.jpg)

已经在别家买过域名也没关系。我演示用的aitoday.xin就是在别家买的，只要托管到 Cloudflare，后面这些功能照样都能用。

## 2. DNS 和那朵小云

域名接进来，第一个要会的是 DNS。

你可以把 DNS 理解成互联网的通讯录：你记住的是名字，电脑要查的是地址。以后开邮箱、挂网站、接各种服务，人家都会让你「添加一条 DNS 记录」，其实就是在通讯录里加一行。

怎么加：点进你的域名 →「DNS」→「记录」→「添加记录」。

填的时候就看三个地方：类型、名称、内容。服务商给你什么，你就照抄什么。

![image](https://pub-8dc0158e77a140d4b502b52ab75765b5.r2.dev/docs/b0a39397b4ed5bf6.jpg)

名称就是你要设置的那个地址：

- 填 @，代表主域名本身，比如 aitoday.xin；
- 填 www、img 这样的词，就是子域名，比如 www.aitoday.xin、img.aitoday.xin。

类型下拉框里有一长串，新手常用的就这五种：

![image](https://pub-8dc0158e77a140d4b502b52ab75765b5.r2.dev/docs/8afd98b03cd246e1.jpg)

简单记三句：

- A 和 CNAME 管网站：服务商给你 IP 就用 A，给你一个域名就用 CNAME。
- MX 管收信。
- TXT 管验证：各种平台让你「验证域名所有权」，十有八九就是让你加一条 TXT。

还有 NS、CAA、SRV 这些类型，新手基本用不到，真遇到了照服务商的说明填就行。

一个常见的坑：同一个名称，CNAME 不能和别的记录并存。比如 www 已经有一条 A 记录，想改成 CNAME，得先把旧的 A 删掉，不然会报错。

再说「代理状态」那一栏的小云：

- 橙色云：流量先经过 Cloudflare，它帮你加速、帮你挡攻击。后面讲的防护，大多靠它。
- 灰色云：它只帮你指个路，访客直接去找你的网站。

![image](https://pub-8dc0158e77a140d4b502b52ab75765b5.r2.dev/docs/f218f6d71a9beadc.jpg)

小云只有 A、AAAA、CNAME 这三种才有，MX 和 TXT 跟网页无关，没得开。

记一句就行：网站一般开橙云，跟邮件有关的记录（比如 mail 开头的那条）保持灰云，按服务商说的来。

## 3. 域名邮箱

有了域名，第一件很有面子的事：域名邮箱。名片上、网站「联系我」那里写 hello@你的域名，比一个随机邮箱专业多了。

Cloudflare 的「电子邮件路由」是免费的。它的思路是转发：别人发到 hello@你的域名 的信，自动转到你平时用的邮箱。不用多开一个邮箱，还在原来的地方收信。

第一步：添加你平时用的邮箱

点进域名 →「电子邮件」→「电子邮件路由」→「目标地址」，在输入框里填你平时用的邮箱，点「添加地址」。

![image](https://pub-8dc0158e77a140d4b502b52ab75765b5.r2.dev/docs/4b46d2c783a15cdf.jpg)

它会给这个邮箱发一封验证信，点信里的「验证电子邮件地址」。

![image](https://pub-8dc0158e77a140d4b502b52ab75765b5.r2.dev/docs/43b13c2dd9716fe7.jpg)

看到这个页面，就验证好了。

![image](https://pub-8dc0158e77a140d4b502b52ab75765b5.r2.dev/docs/25286ebd329f87c1.jpg)

第二步：建一条转发规则

回到「路由规则」→「创建路由规则」：

- 电子邮件匹配模式填 hello，后面选你的域名；
- 操作选「发送到电子邮件」；
- 目标选刚才验证好的邮箱；
- 点「保存」。

![image](https://pub-8dc0158e77a140d4b502b52ab75765b5.r2.dev/docs/346a607437f23b9d.jpg)

列表里出现 hello@你的域名，状态是「活跃」，就配好了。

![image](https://pub-8dc0158e77a140d4b502b52ab75765b5.r2.dev/docs/d99a8aaf317d6dad.jpg)

我用另一个邮箱给hello@aitoday.xin

发了一封信，Gmail 这边几秒钟就收到了。

![image](https://pub-8dc0158e77a140d4b502b52ab75765b5.r2.dev/docs/ad86cacce1247eb0.jpg)

说清楚免费的边界：免费的只有收信转发。你直接回复的话，发件人还是你的 Gmail；想让网站自动给用户发验证码、发通知，那是另一个功能，要开 Workers 付费版，每月 5 美元起。

## 4. Workers：不买服务器，网站直接上线

一个只放文字和图片的网站很简单。但只要你想让访客「提交」点什么，比如报名、留言、登录，就需要一段在后台跑的程序。Cloudflare 放这段程序的地方，叫 Workers。

入口：左侧菜单「计算」→「Workers 和 Pages」，点右上角「创建应用程序」。

![image](https://pub-8dc0158e77a140d4b502b52ab75765b5.r2.dev/docs/0394828885b97216.jpg)

点进去能看到好几种上线方式，按你手上有什么来选：

- 项目在 GitHub 或 GitLab 上：选「Continue with GitHub」或「Connect with GitLab」，连上你的仓库。以后你每往仓库推一次代码，它就自动重新部署一次，不用再进后台点。真实项目最推荐这种。
- 只有一堆做好的网页文件：选「Upload your static files」，把文件夹直接拖进去就上线了，连 GitHub 都不用。
- 什么都还没有，想先试试：选「从 Hello World! 开始」或「选择模板」，拿一个现成的小程序当模板跑起来。

![image](https://pub-8dc0158e77a140d4b502b52ab75765b5.r2.dev/docs/cb7e5b29dda81e64.jpg)

这里我们演示最后一种：用 Hello World 模板测试一下，看看一个程序从创建到上线要几步。

- 选「从 Hello World! 开始」；
- 名字可以不改，直接点右下角「部署」；

![image](https://pub-8dc0158e77a140d4b502b52ab75765b5.r2.dev/docs/bfef46dd14d2e4fc.jpg)

- 部署完，打开它分给你的 workers.dev 地址，页面上出现「Hello World!」。

点几下，一个程序就上线了，还自带一个网址。跑通以后，你自己的项目就可以换成 GitHub 或拖文件的方式上线，步骤差不多。

它和传统服务器最大的不同是：程序不是放在某一台机器上，而是放在 Cloudflare 遍布全球的节点上，谁访问就在离谁近的地方跑。你不用买服务器、不用装系统。免费版每天 10 万次请求，个人项目基本够用。

## 5. 三种存储，按用途选

网站总要存东西。Cloudflare 给了三种存储，别记名字，记用途：

![image](https://pub-8dc0158e77a140d4b502b52ab75765b5.r2.dev/docs/84a94ced8906754d.jpg)

R2：放图片和文件

R2 可能是 Cloudflare 给得最大方的一样东西。

别家的对象存储，不光收存储费，别人每下载一次你的文件，还要收一次流量费。网站一火，账单比你先火。R2 不收下载流量费，每月还有 10GB 免费存储。

怎么用：

- 左侧菜单「存储和数据库」→「R2 对象存储」→「创建存储桶」，起个名字，其他默认；

![image](https://pub-8dc0158e77a140d4b502b52ab75765b5.r2.dev/docs/3bc800fece369b64.jpg)

- 进到存储桶里，把图片拖进去上传；

![image](https://pub-8dc0158e77a140d4b502b52ab75765b5.r2.dev/docs/fcae88fe587e690c.jpg)

- 存储桶的「设置」→「自定义域」→「添加」，接上你自己的子域名，比如 img.aitoday.xin。

![image](https://pub-8dc0158e77a140d4b502b52ab75765b5.r2.dev/docs/00bd2fd88907eda3.jpg)

接好以后，换一个没登录的无痕窗口，用img.aitoday.xin

加文件名打开，图片直接就能访问。

![image](https://pub-8dc0158e77a140d4b502b52ab75765b5.r2.dev/docs/162ad44a39774d64.jpg)

D1：一个真正的数据库

![image](https://pub-8dc0158e77a140d4b502b52ab75765b5.r2.dev/docs/f3fc0a18e3a8a407.jpg)

「存储和数据库」→「D1 SQL 数据库」→「创建数据库」，起个名字。

进到数据库的「控制台」，三句话试一下：pgsql CREATE TABLE notes (id INTEGER PRIMARY KEY, title TEXT NOT NULL);

建一张表，写一条记录，再查出来，结果就在下面。

![image](https://pub-8dc0158e77a140d4b502b52ab75765b5.r2.dev/docs/9ae1273de38ab870.jpg)

以后报名表、留言板的数据，都能存在这里。

KV：放公告和开关

KV 就是一个名字对应一段内容。我建了一个叫 notice 的键，内容写「周六晚上维护」。

![image](https://pub-8dc0158e77a140d4b502b52ab75765b5.r2.dev/docs/df7e2898368bcdba.jpg)

要注意：KV 同步到全球要一点时间，别拿它存余额、库存这种必须实时准确的东西。

这三样，都是通过「绑定」接到你的 Worker 上的。代码不用自己写，文末有一段提示词，交给 AI 就行。

## 6. 免费 HTTPS 和缓存

HTTPS

网站地址前面那把小锁，也就是 HTTPS，以前要花钱买证书。用 Cloudflare，证书自动配好，免费，还自动续期。

新手最常踩的坑：用自己服务器的，如果浏览器提示「重定向次数过多」，多半是「SSL/TLS」→「加密模式」这里选了「灵活」。服务器有证书的话，改成「完全（严格）」。

![image](https://pub-8dc0158e77a140d4b502b52ab75765b5.r2.dev/docs/9d091a6e38c956fa.jpg)

(由于超过图片限制，已经没有图片了。要完整的可以看评论区的链接。)

缓存

开了橙云以后，你网站上的图片、样式文件会存在全球节点上，访客就近拿，网站更快。

最常见的问题是：明明换了图，网站上还是旧的。

怎么清：点进域名 →「缓存」→「配置」→「自定义清除」，清除方式选 URL，把那张图的地址填进去，点「清除」。右下角提示成功就好了。

## 7. 防护全家桶

网站一上线，迟早会遇到坏人。防护是 Cloudflare 的老本行。常见的坏人有三种。

第一种：用海量流量把网站冲垮（DDoS）

只要开着橙云，基础防护自动生效，免费版也有，你什么都不用做。

第二种：扫后台

比如你的网站根本不是 WordPress，日志里却天天有人在试 /wp-admin 这个地址找漏洞。那就建一条规则，直接挡掉。

怎么建：点进域名 →「安全性」→「安全规则」→「创建规则」→「自定义规则」：

- 字段选「URI 路径」，运算符选「包含」，值填 /wp-admin；
- 操作选「阻止」；
- 点「部署」

部署完再访问这个地址，直接被挡在门外。

第三种：机器人自动填表单、刷接口

用 Turnstile。左侧菜单「应用程序安全」→「Turnstile」→「添加小组件」，填名称和你的域名，点「创建」。

创建完它会给你两把钥匙：站点密钥和密钥。把它们交给网站接上。第二把「密钥」只能放在后端，千万别截图发出去，也别写进前端代码。

接上之后长这样。这是我自己做的一个网站，点生成之前，会先弹出「请验证您是真人」。正常人点一下就过，机器人就卡在这。它也是免费的。

大坑：只在网页上放组件没用，机器人可以跳过网页直接打你的后台。一定要让后台再校验一次。让 AI 写代码的时候，这句话一定要写进要求里。

## 8. AI 全家桶

现在做网站，很多人都想加点 AI 功能，菩萨也准备好了。

Workers AI：直接调模型

左侧菜单「AI」→「Workers AI」。它自己的网络里就跑着一大堆开源模型，文字、图片、语音都有，你的网站可以直接调，每天有免费额度。做个文章摘要、自动分类，完全够用。

AI Gateway：AI 调用的监控台

等你频繁调 AI 了，你会想知道哪次失败了、花了多少钱。AI Gateway 就是个监控台，也能接别家的模型。

AI 搜索：按你的资料回答问题

这个我觉得最有意思。把你的资料传上去，它就能按你的资料回答问题。

「AI」→「AI 搜索」→ 新建一个，上传文档。我传了一份网站的常见问题 faq.md。

然后在 Playground 里问：

- 问「怎么联系泊舟」，文档里有，它答出来了，还告诉你出处是 faq.md；
- 再问「泊舟养了几只猫」，文档里没有，它老老实实说找不到，不瞎编。

网站上的智能客服，就是这么来的。

## 9. 定时任务、统计和告警

几个小功能，不起眼，但很省心。

定时任务

让程序按时自动跑，比如每 30 分钟检查一次、每天早上统计一下昨天的报名。

怎么设：进到你的 Worker →「设置」→「触发事件」→「Cron 触发器」，选执行频率，比如每 30 分钟。

要注意：下面列出的时间是 UTC，比北京时间慢 8 个小时。保存前看一眼，别算错了。

网站统计

「Web Analytics」→ 添加站点。有多少人来、从哪来、页面快不快，不用另装统计工具。

告警

「通知」→「创建通知」，选「DDoS 攻击」，设置接收邮箱。网站被攻击了，第一时间发邮件告诉你。建议上线第一天就开。

## 10. 免费内网穿透

这一件我最推荐。

你家里电脑上跑着一个网页，平时只有在家里才能打开，出了门、换个网络，就访问不到了。

比如我在自己电脑上，用一行命令跑了一个最简单的小网页：python3 -m http.server 8080

装好 Cloudflare 的命令行工具 cloudflared，再开一个终端，敲一行命令：cloudflared tunnel --url http://localhost:8080

它就给你一个trycloudflare.com

结尾的公网地址。

不管你人在公司、在咖啡店，还是把地址发给朋友，都能直接打开。我在手机上打开这个地址，家里电脑上的网页出来了。

这就是大家常说的内网穿透：不用买服务器，不用公网 IP，也不用改路由器。

长期用要加门禁：这种临时地址适合演示和临时分享。如果是长期要用的，比如家里 NAS 的管理后台，就在「Zero Trust」→「访问控制」→「应用程序」里配上 Access，只允许你指定的人登录，别人拿到地址也进不来。记住顺序：先配好门禁，再公开地址。

## 为什么这么大方

说到这，你可能在嘀咕：免费的是不是最贵的？

Cloudflare 是一家上市公司，真正赚钱的是大企业。免费用户对它有两个价值：

- 流量就是情报。全世界大量网站的流量从它这经过，攻击长什么样它看得最清楚，防护就越做越准。
- 今天的个人开发者，明天可能就是付费的公司。

所以它的免费不是慈善，是一门生意，只是这门生意对我们正好很划算。

## 它不灵的时候

但也得说几句实话。

第一，国内访问。Cloudflare 在中国大陆的节点，要企业版单独开通，还得备案。我们用免费版，国内用户打开有时快有时慢。用户主要在国内的话，先实测，别想当然。

第二，免费有边界。每样都有额度，大部分个人项目用不完。但网站真火了，或者要发验证码邮件，就得开付费版，起步每月 5 美元。

第三，鸡蛋别全放一个篮子。域名、网站、数据都在一个账号里，账号出问题就全停。重要数据记得定期导出备份。

## 从哪一件开始

不用一口气全学完。对号入座，挑一件你现在就需要的，配好、验证能用，再用下一个。

需要写代码的那些，比如接数据库、加人机验证，可以直接交给 Codex 或者 Claude Code。下面这段通用提示词，复制过去，把【】里换成你的需求就行：

这是一个部署在 Cloudflare 上的项目。先读一遍项目，告诉我现在用了哪些 Cloudflare 服务，暂时不要改任何东西。

我想实现：【写你的需求】

要求：
1. 先说明要用哪个 Cloudflare 服务、为什么、我需要准备什么。
2. 先在本地或测试环境跑通，并告诉我怎么验证。
3. 没有我的确认，不部署、不改线上数据和 DNS。
4. 密钥只放在后端的 Secret 配置里，不写进代码、不提交 Git、不打日志。
5. 动手前说明如果出问题怎么回滚。
