我们通过 Wise 港币账户接收 X 工资后，Stripe 会自动将美元换汇成港币，还有其中各种提现打款操作，一共需要 10 HKD 的手续费。

收到这笔钱后建议在 Wise 中存放个两三天，不要马上操作提现，不让容易被封控认定为快入快出，Wise 账户非常重要，我们还是要好好珍惜的！😭

一旦被封，很难再次注册！！！

接下来说说如何提现回国，首先你需要将港币在 Wise 中兑换成人民币。

进击港币账户，并点击「兑换」。

![image](https://pub-8dc0158e77a140d4b502b52ab75765b5.r2.dev/docs/70f3caf47007ce92.jpg)

这一步会收取一定的手续费，如图所示，兑换 5600 HKD 大概需要 23 HKD 的手续费，换算成人民币就是 20 块钱，这里的手续费是根据你的兑换金额来计算的。

![image](https://pub-8dc0158e77a140d4b502b52ab75765b5.r2.dev/docs/b76733a36322d666.jpg)

兑换完成后，你需要到支付宝搜索「闪速收款」，开通支付宝跨境汇款服务。

这里有一点必须提一下，如果你方便让你的家人开通，推荐让家人开通。这样我们就可以在 Wise 的汇款理由里选择「向家人汇款」，也就是赡家，这么做的好处是什么呢，后续不会被支付宝要求提交各种材料而被卡。

![image](https://pub-8dc0158e77a140d4b502b52ab75765b5.r2.dev/docs/70c6f08b82499b19.jpg)

（这里我用了我爸的支付宝操作，秒到账，没有被要求提交资料证明资金来源。）

如果家人不方便操作，那么也是可以用自己的同名支付宝账户的，开通即可，用自己的账户的话汇款理由就选择「储蓄」。

![image](https://pub-8dc0158e77a140d4b502b52ab75765b5.r2.dev/docs/8aa3f72f90a4deeb.jpg)

开通完成后，我们回到 Wise 选择人民币账户，点击「汇款」，添加一位收款人，对方的货币选择「人民币」，然后选择「电子钱包」，选择「支付宝」，因为支付宝应该是手续费最低的，固定为 20.77 人民币。

![image](https://pub-8dc0158e77a140d4b502b52ab75765b5.r2.dev/docs/8d457abbc2fa65d8.jpg)

接下来选择收款人类型，如果是自己，就选「我本人」，如果是家人，就选「其他人」。

接下来填写姓名，填写刚刚支付宝闪速收款账户的名字。

我的填法是：First Name (名) 在前，Last Name (姓) 在后，并首字母大写其余小写，中间空格，也就是 Jiahao He，实测正常到账。

然后选择填写「电话号码」与「电子邮箱」其中之一，我的支付宝闪速收款提供的是电话号码，我就选择填写了电话号码。

![image](https://pub-8dc0158e77a140d4b502b52ab75765b5.r2.dev/docs/2f0a79711cb3ba53.jpg)

之后一路继续提交即可，一般是秒到账，不放心的话，大家可以白天操作，更稳。我自己是凌晨操作的，也是秒到账了。

![image](https://pub-8dc0158e77a140d4b502b52ab75765b5.r2.dev/docs/a90a22aa4e4e43eb.jpg)

![image](https://pub-8dc0158e77a140d4b502b52ab75765b5.r2.dev/docs/e601613a6de71348.jpg)

## 手续费计算，8.5 + 20 + 20.77 ≈ 50 RMB，心痛啊 💔，但应该也是最低的手续费操作了，其他方法要八十一百的。

这里一定要把港币换成人民币，要不然直接从港币提现支付宝，手续费好像会多很多。

接下来说说如果你遇到支付宝入金风控了，需要提交材料怎么操作。

登录 X 收益绑定的 Stripe Express，把 X Crop 的收入到账截图，再把 Wise 中的 Stripe 提现到账截图，金额要对应，截图也要截完整！

材料备注：「收入来源于 X (formerly Twitter) 的原创内容分成」。
